\section{Thiết kế Kiến trúc 3 tầng (3-Tier Architecture)}
Hệ thống được thiết kế theo chuẩn kiến trúc 3 tầng phân tách độc lập (Hình~\ref{fig:arch}):
\begin{itemize}
    \item \textbf{Presentation Tier:} Single Page Application (React Vite, Tailwind CSS, Lucide Icons, Smart Table Renderer).
    \item \textbf{Application Logic Tier:} FastAPI Async (Python), Pydantic Data Validation, AI Dual-layer Engine, RBAC Security.
    \item \textbf{Data Tier:} Hệ quản trị CSDL quan hệ 11 bảng chuẩn hóa 3NF và dịch vụ đám mây Google Gemini.
\end{itemize}

\section{Thiết kế Cơ sở dữ liệu 11 bảng chuẩn hóa 3NF}
Cơ sở dữ liệu được tổ chức chặt chẽ với 11 bảng: \texttt{roles}, \texttt{users}, \texttt{categories}, \texttt{suppliers}, \texttt{locations}, \texttt{products}, \texttt{inventory\_items}, \texttt{inventory\_transactions}, \texttt{inventory\_transaction\_items}, \texttt{audit\_logs}, \texttt{ai\_query\_logs} (Hình~\ref{fig:erd}).
