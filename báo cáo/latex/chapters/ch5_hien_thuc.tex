\section{Môi trường cài đặt và Công nghệ}
\begin{itemize}
    \item \textbf{Backend:} Python 3.14, FastAPI Async, SQLAlchemy ORM, Pydantic v2, Jose JWT, Passlib (Argon2 / Bcrypt).
    \item \textbf{Frontend:} Node.js v18+, React 18, Vite, Tailwind CSS, Lucide React, Axios.
    \item \textbf{AI Cloud:} Thư viện \texttt{google-genai} kết nối mô hình Gemini 1.5 Flash.
\end{itemize}
