\chapter{ĐỐI CHIẾU RUBRIC VÀ HƯỚNG DẪN VẬN HÀNH}

\section{Bảng đối chiếu 40 tiêu chí Rubric học phần AIA331}
Nhóm 11 đã tự đối chiếu và đáp ứng trọn vẹn 40/40 tiêu chí Rubric môn học qua cả 4 giai đoạn:
\begin{enumerate}
    \item \textbf{Giai đoạn KT1 (10 tiêu chí):} Đầy đủ bài toán, Actor, Use-case, ERD 11 bảng, kiến trúc 3 tầng.
    \item \textbf{Giai đoạn KT2 (10 tiêu chí):} Mã nguồn Backend FastAPI chuẩn mực, CRUD APIs, Database ORM, RBAC.
    \item \textbf{Giai đoạn KT3 (10 tiêu chí):} Tích hợp AI kép, Prompt Ground-truth, xử lý triệt để chia 0, phát hiện dị biệt.
    \item \textbf{Giai đoạn Đồ án Cuối kỳ (10 tiêu chí):} Giao diện SaaS Dark Mode, Chat Console NLP, hồ sơ báo cáo hoàn chỉnh.
\end{enumerate}

\section{Hướng dẫn khởi chạy và tài khoản thử nghiệm}
\begin{itemize}
    \item \textbf{Khởi chạy Backend:} \texttt{python -m uvicorn app.main:app --host 127.0.0.1 --port 8000 --reload}
    \item \textbf{Khởi chạy Frontend:} \texttt{npm run dev} (Truy cập \url{http://localhost:3000})
    \item \textbf{Tài khoản kiểm thử mặc định:}
    \begin{itemize}
        \item Quản trị viên: \texttt{admin} / \texttt{Admin@123} (Role: ADMIN)
        \item Thủ kho: \texttt{warehouse} / \texttt{Warehouse@123} (Role: WAREHOUSE)
        \item Kế toán: \texttt{accountant} / \texttt{Accountant@123} (Role: ACCOUNTANT)
    \end{itemize}
\end{itemize}
